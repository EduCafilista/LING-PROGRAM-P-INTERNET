# DevJobs

Trabalho da disciplina de Linguagens de Programação para Internet.

Mural de vagas de TI feito com HTML, CSS e JavaScript puro. As vagas ficam em um array no `js/script.js` e são renderizadas na tela em cards. Tem busca por texto, filtro por tipo (remoto, presencial ou híbrido) e tema claro/escuro salvo no navegador.

## Como abrir

É só abrir o `index.html` no navegador.
